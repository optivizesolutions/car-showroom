# AUREL — Premium 3D Showroom

An original, responsive car-showroom experience built with Next.js, TypeScript, Three.js, and React Three Fiber. The vehicle in this starter is modeled from original procedural geometry; no third-party car asset is included.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

- `app/page.tsx` — brand copy, specs, and finish selector.
- `components/Showroom.tsx` — Three.js car geometry, materials, lighting, and camera controls.
- `app/globals.css` — responsive visual design.
